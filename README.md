# COMMAND BATTLE

ドラゴンクエスト風のターン制コマンドバトルゲーム

## 概要

ブラウザで遊べるシンプルなコマンドバトルゲームです。勇者を操作してモンスターと戦い、世界に平和を取り戻しましょう。

## 特徴

- レトロなドット文字フォントを使用した懐かしいUI
- ターン制のコマンドバトルシステム
- 4つのコマンドから選択して戦う
- ドラゴンとの壮絶なバトル

## ゲームシステム

### プレイヤー情報
- **名前**: ゆうしゃ
- **レベル**: 20
- **最大HP**: 138
- **最大MP**: 70
- **装備**: ロトの剣、ロトのよろい、水鏡の盾

### コマンド

| コマンド | 説明 |
|---------|------|
| **こうげき** | モンスターに通常攻撃を行う |
| **どうぐ** | やくそうを使ってHPを回復（23〜30ポイント） |
| **かいふく** | 回復の呪文でHPを回復（MP10消費、85〜100ポイント回復） |
| **にげる** | 戦闘から逃走を試みる（失敗する） |

### 敵の行動
モンスターは以下の2つの攻撃をランダムで使用します：
- **こうげき**: 通常の物理攻撃
- **ほのお**: 炎のブレス攻撃

## 遊び方

1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く
3. 2秒後にモンスターが出現
4. コマンドを選択して戦闘開始

## 技術仕様

- **言語**: HTML5, CSS3, JavaScript (ES6)
- **フレームワーク**: Bootstrap 5.0.2
- **フォント**: JF-Dot-k6x8（レトロなドットフォント）

## ゲームの流れ

1. ゲーム開始時、プレイヤーのステータスが表示される
2. 2秒後にモンスターが出現
3. 4つのコマンドから1つを選択
4. プレイヤーの行動後、モンスターが攻撃
5. どちらかのHPが0になるまで戦闘が続く

## 勝利条件

モンスターのHPを0にすると「世界に平和がもどったのだ！」と表示され、ゲームクリア。

## 敗北条件

プレイヤーのHPが0になると「あなたは、しにました。」と表示され、ゲームオーバー。

## ライセンス

このプロジェクトは自由に使用できます。

## 開発者向け情報

### ダメージ計算式

#### プレイヤーの攻撃
```
ダメージ = ((攻撃力 - 敵守備力/2) / 2) × (5〜10のランダム値) × 0.1
```

#### モンスターの通常攻撃
```
ダメージ = ((攻撃力 - プレイヤー守備力/2) / 2) × (5〜10のランダム値) × 0.1
```

#### モンスターの炎攻撃
```
ダメージ = (65 + 0〜7のランダム値) × 2/3
```

### カスタマイズ

`js/main.js` ファイルの以下のパラメータを変更することで、ゲームバランスを調整できます：

- プレイヤーのステータス（HP、MP、ちから、すばやさ）
- 装備の性能（武器、防具、盾の攻撃力・守備力）
- モンスターのステータス（HP、攻撃力、守備力）
- 回復量の範囲
